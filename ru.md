# Универсальная сервиторная архитектура

## Теримины
- **Предметная область (домен)** - область реального мира, которую описывает и оптимизирует программное обеспечение;
- **Доменная логика** - это слой в программной архитектуре, отвечает за бизнес-правила и обработку данных, относящихся к предметной области;
- **Бизнесс-логика** - это набор правил, процессов и операций, которые отображают предметную область;
- **Юнит, бизнесс-юнит (Unit)** - одно бизнесс-правило (операция, процесс);
- **Сервитор (Servitor, Servant)** - это объект, который содержит только один бизнесс-юнит;
- **Сервис (Service)** - это объект, который содержит больше одного бизнесс-юнита;
- **Универсальная сервиторная архитектура (УСА)** - концепция построения слоя доменной логики с использованием сервиторов;
- **DAO (Data Access Object, ДАО)** - Объект доступа к данным. Паттерн проектирования, который предназначен для изолиции логики доступа к данным от бизнесс-логики;
- **Mapper (Маппер)** - Это компонент, который отвечает за преобразование (маппинг) объектов из одной модели  в другую;
